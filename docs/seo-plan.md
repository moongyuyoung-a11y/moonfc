# 검색 상위 노출 운영 계획

목표 키워드: **피트니스 컨설팅, 헬스장 경영 컨설팅, FC 교육, 피트니스경영** (+ FC 양성, 피트니스 컨설턴트, 헬스장 매출)

검색 순위는 사이트 설정만으로 "정해지는" 것이 아니라, 검색엔진이 아래 세 가지를 확인한 뒤 결정합니다. 홈페이지는 1번을 갖췄고, 2·3번은 배포 후 운영으로 쌓아야 합니다.

## 1. 사이트 자체 (완료)

| 항목 | 상태 |
| --- | --- |
| 키워드가 들어간 title / h1 / 첫 문단 | 홈 `피트니스 컨설팅 · 헬스장 경영 컨설팅`, 컨설팅 `헬스장 경영 컨설팅 · 피트니스센터 매니지먼트`, FC 교육 `FC 교육 · 피트니스 컨설턴트 양성 과정`, 인사이트 `피트니스경영 인사이트` |
| 구조화 데이터 | Organization, LocalBusiness, Person, Service, FAQPage, Article, BreadcrumbList |
| 속도·모바일·접근성 | 라이트하우스 모바일 95+ / 100 / 100 / 100 |
| AI 검색용 | llms.txt, 각 페이지 첫 문단 "질문에 바로 답하는 문장", FAQ 질문=h3 구조, AI 크롤러 허용 |
| 사이트맵·RSS | 자동 생성 |

## 2. 검색엔진 등록 (배포 직후, `launch-checklist.md`)

- 구글 서치콘솔 + 네이버 서치어드바이저에 사이트맵·RSS 제출
- 네이버는 등록 후에도 반영이 느리므로 새 글마다 "웹 페이지 수집 요청"
- 구글 비즈니스 프로필 / 네이버 플레이스(스마트플레이스)에 같은 상호·대표명·URL 로 등록 → 브랜드 검색 시 사이트가 함께 노출

## 3. 콘텐츠와 신뢰 신호 (지속)

검색엔진과 AI 는 "이 주제를 오래, 구체적으로, 실제 경험으로 다루는 사이트"를 위로 올립니다.

**글 발행 (가장 중요)**
- 월 2편 이상. 한 편에 한 키워드. 예시 주제:
  - 헬스장 경영 컨설팅 — "헬스장 경영 컨설팅은 무엇을 하는가", "컨설팅 전 대표가 직접 확인할 5가지 숫자"
  - 피트니스 컨설팅 — "피트니스센터 매출 구조 진단 체크리스트"
  - FC 교육 — "신입 FC 첫 달 교육 커리큘럼", "FC 상담 스크립트 예시"
  - 피트니스경영 — "재등록률 계산법", "PT 매출 비중 적정선"
- 세미나·강의 후기는 기관명·날짜·인원을 적어 글로 남김 (E-E-A-T)
- 글마다 `service`, `faq` frontmatter 로 내부 링크 연결

**대표 소개 채우기**
- `src/lib/profile.ts` 의 경력·강의 이력·자격을 실제 값으로. 검색엔진이 "누가 쓴 글인지"를 판단하는 근거

**외부 신호**
- 유튜브·인스타그램 프로필과 영상 설명란에 홈페이지 URL
- 출강한 대학·기업의 공지/후기 페이지에 홈페이지 링크 요청
- 네이버 블로그/카페, 브런치 등에 글을 올릴 때 원문 링크를 홈페이지로
- 컨설팅한 센터 홈페이지에 "컨설팅 파트너" 링크 (동의 시)

**측정**
- 서치콘솔 "검색어" 보고서에서 목표 키워드 노출·클릭·순위 확인 (월 1회)
- 순위가 5~20위에 머무는 키워드는 해당 글을 보강(사례·숫자·FAQ 추가)

## 예상 일정

| 시점 | 기대 |
| --- | --- |
| 배포 후 1~2주 | 브랜드명(문프스, MOONFC) 검색 시 1위 |
| 1~3개월 | 롱테일 키워드(FC 상담 스크립트, 재등록률 등)로 유입 시작 |
| 3~6개월 | 글 10편 이상 축적 시 "헬스장 경영 컨설팅", "FC 교육" 첫 페이지 진입 가능 |
| 6개월~ | "피트니스 컨설팅" 등 경쟁 키워드는 외부 링크·꾸준한 발행에 따라 결정 |
